# ⭐ Rating System

A simple and interactive star rating application built with React. Users can select a rating, receive feedback, and interact with a clean, responsive UI.

## 🚀 Features

- ⭐ Interactive star rating component
- 🎨 Dynamic hover effects
- 📊 Displays selected rating
- 💬 User feedback based on rating
- ⚛️ Built with React functional components and hooks

## 🛠️ Technologies Used

- React
- JavaScript (ES6+)
- CSS3
- Vite

[View Live Demo](https://rstrauman.github.io/rating-system)

## 📦 Installation

Clone the repository:

```bash
git clone https://github.com/rstrauman/rating-system.git
```

Navigate to the project directory:

```bash
cd rating-system
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

## 🎯 How It Works

1. Hover over the stars to preview a rating.
2. Click a star to submit your rating.
3. The application updates the UI to reflect the selected score.
4. Users receive feedback based on their rating.
